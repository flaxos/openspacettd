COMMONWEALTH SAGA — WORLD AND CONNECTION SCHEMA
Version: research reconstruction 1.0
Scope: Pandora's Star / Judas Unchained
Purpose: source-informed OpenSpaceTTD universe planning

======================================================================
0. HOW TO READ THIS FILE
======================================================================

This is a reconstruction, not an official exhaustive route map.

World existence and connection certainty are separate:
- A world may be named in a source while its transport connections are not.
- Do not promote an assumed connection to canon because its endpoints exist.

CONNECTION EVIDENCE

E = EXPLICIT
    A retrieved novel passage describes the connection.

R = REFERENCE-SUPPORTED
    A secondary reference identifies the connection, or the connection follows
    the novel's stated Earth-to-Phase-One structure combined with documented
    Phase One membership.
    An individually described journey has not necessarily been verified.

I = INFERRED
    There is a specific geographical, sector, journey or historical reason
    to propose this connection, but a direct permanent link is not established.

A = ASSUMED FOR GAME COMPLETION
    The direct connection is not documented in the retrieved sources.
    This is an editable game-design allocation, not a canonical discovery.

U = UNKNOWN / NOT ASSIGNED
    No direct connection is supplied.

PHASES

P1 = Phase One.
P2 = Phase Two.
P3 = Phase Three.
?  = Not established here.
NA = Phase classification not applicable.

These are the setting's expansion-phase labels.
Do not automatically equate them with a rigid game technology tier.
A frontier-like world can still belong to Phase Two.

TIME

The ordinary network below is a PRE-INVASION / PEACETIME reconstruction.

Historical demonstrations, emergency evacuation links, private retargetings,
and later-era locations are listed separately.

Do not activate all historical connections simultaneously.

TRANSPORT MODES

RAIL          = railway wormhole connection.
GATE          = wormhole connection; through-running rail not established here.
SCHEDULED     = wormhole with restricted operating periods.
PRIVATE       = private/restricted wormhole access.
EXPLORATION   = exploratory wormhole; not an ordinary public freight service.
DATA          = communications connection, not train or bulk-cargo access.
SILFEN_ROUTE  = access through the Silfen path network; intermediate paths unknown.
ORBITAL       = wormhole to orbital infrastructure.
SHUTTLE       = local spacecraft transfer.
AIRCRAFT      = local atmospheric flight.
NONE          = no active transport edge assigned.

NETWORK CONVENTION

Each catalogue row supplies ONE connection to its named CONNECTS_TO endpoint.

Treat ordinary links as bidirectional unless a special record says otherwise.
Connections listed under child worlds also belong to their parent world.

Example:
  Merredin -> Mito
  Clonclurry -> Merredin
  Valvida -> Merredin

Therefore Merredin's neighbours are:
  Mito, Clonclurry, Valvida.

"CONNECTS_TO" is not necessarily the world's only connection.

Never infer a direct gate merely from:
- two worlds being near each other;
- shared corporate ownership;
- a train ticket mentioning both destinations;
- a shared phase;
- a radio message being received;
- an evacuation itinerary without its intermediate stops.

2. INFERENCE AND ASSUMPTION REGISTER
======================================================================

R0 — EARTH / PHASE ONE
     S04 describes Earth as the junction for Phase One worlds.
     S01, S02, S10, S14 and S17 identify relevant Phase One members.
     Their Earth links are recorded R rather than pretending that every
     individual gateway was independently described in a retrieved passage.

I1 — VERONA / SAVILLE
     Saville is discussed as an outward-exploration junction in the same
     sector as Gralmond and Tanyata.
     Verona is the established sector hub.
     Proposed direct link: Verona <-> Saville.
     Direct permanent connection remains unverified.

I2 — WESSEX / ELAN
     Wessex infrastructure serves Elan during evacuation.
     A normal pre-war Wessex <-> Elan connection is plausible.
     The emergency evidence does not independently prove peacetime service.

I3 — BALKASH / ANAGASKA
     Anagaska is a Phase Three world eight light-years from Balkash.
     Proposed local expansion branch: Balkash <-> Anagaska.
     Proximity alone does not establish a canonical gate.

I4 — AUGUSTA / CRESSAT
     Travel to Cressat is arranged through an Augusta collection point.
     Proposed private direct link: Augusta <-> Cressat.
     An intermediate transport leg remains possible.

I5 — WESSEX / HANKO
     Hanko's evacuation is discussed alongside Wessex-based wormholes.
     Proposed normal sector attachment: Wessex <-> Hanko.
     The precise pre-war direct connection is not established here.

A0 — UNDOCUMENTED ORDINARY CONNECTION
     Attach the otherwise unplaced world to a named Phase One hub.
     Preserve a sparse branching network instead of inventing a mesh.
     The particular hub allocation is an original game-design choice.
     It is not an inference from undisclosed astronomical coordinates.

A1 — SILVERGALDE ENTRY
     A CST railway gateway at Silvergalde is reference-supported.
     Its Commonwealth-side endpoint has not been reliably verified here.
     Bayovar is supplied ONLY as a provisional game endpoint.
     Do not cite Bayovar <-> Silvergalde as established canon.

A2 — FRONTIER / WARTIME-SECTOR GROUPING
     Group selected affected worlds around the Wessex/Anshun branch for
     a coherent game scenario.
     This does not establish that every affected world shared those hubs.
     Exact parent assignments remain assumptions.

A3 — EXPLORATION / RESTRICTED ACCESS
     Attach a research or restricted world to a suitable operational hub.
     Access controls and the chosen parent are game assumptions unless sourced.

- Treat those timings as a source-specific operating detail, not proof of
  uninterrupted service throughout every event in the novels.

12. IMPLEMENTATION RULES FOR OPENSPACETTD
======================================================================

Keep the source reconstruction separate from game topology.

For every world:
  world_id
  canonical_reference_name
  display_name
  phase
  phase_evidence
  location_type
  era
  source_ids

For every connection:
  connection_id
  endpoint_a
  endpoint_b
  connection_type
  evidence_class
  source_ids
  inference_or_assumption_id
  availability
  access_policy
  valid_era
  permits_through_running_train
  enabled_in_game

Suggested graph modes:

SOURCE_ONLY
  Include E and R links.
  Preserve disconnected worlds where no route is known.
  Apply historical/private/modal restrictions.

RECONSTRUCTED
  Include E, R and I links.
  Keep inferred connections visibly tagged.

PLAYABLE_COMPLETION
  Include selected A links as well.
  These are game-design additions, never new canon.

Do not automatically convert:
  PRIVATE -> public railway
  DATA -> cargo railway
  SILFEN_ROUTE -> wormhole railway
  ORBITAL + SHUTTLE -> uninterrupted train route
  evacuation itinerary -> permanent direct gate

For a larger universe:
  Generate additional unnamed/procedural colonies as ORIGINAL GAME CONTENT.
  Do not invent hundreds of names and attribute them to Hamilton.

Core structural rule:
  Earth / Phase One junctions
    -> outward sector worlds
    -> further expansion branches

Known branches override generated topology.
Unknown branches remain editable assumptions.
