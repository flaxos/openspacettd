preserves substantial existing work. Substitute the exact published head from the

```bash
(
set -eu
food_expected='<EXACT_PUBLISHED_FOOD_HEAD>'
food_branch=codex/a1-first-paid-core-food
# Choose a new directory; git clone stops if it already exists/nonempty.
```

For an existing repository, run from its root in Bash. This stops on dirty/untracked,
missing-upstream, ahead/diverged or moved-head state. It never resets, discards,
rebases, merges another feature or force-pushes local work.

```bash
(
set -eu
stop() { printf '%s\n' "STOP: $*" >&2; exit 1; }
food_branch=codex/a1-first-paid-core-food
food_expected='<EXACT_PUBLISHED_FOOD_HEAD>'
[ -z "$(git status --porcelain --untracked-files=all)" ] || stop 'preserve local edits/untracked files before sync'
git remote get-url openspace >/dev/null || stop 'verify the intended openspace remote first'
git fetch openspace
food_upstream=$(git rev-parse --abbrev-ref '@{upstream}') || stop 'inspect current branch with no upstream'
git merge-base --is-ancestor HEAD "$food_upstream" || stop 'current branch is ahead or diverged'
[ "$(git rev-parse "openspace/$food_branch")" = "$food_expected" ] || stop 'published head moved; inspect its evidence'
if git show-ref --verify --quiet "refs/heads/$food_branch"; then
    git merge-base --is-ancestor "$food_branch" "openspace/$food_branch" || stop 'local food branch is ahead or diverged'
    git switch "$food_branch"
    git merge --ff-only "openspace/$food_branch"
else
    git switch -c "$food_branch" --track "openspace/$food_branch"
fi
[ "$(git rev-parse HEAD)" = "$food_expected" ] || stop 'unexpected final head'
[ -f build/build.ninja ] || cmake -B build -G Ninja
ninja -C build -j2
)
```
