# OpenSpaceTTD Commonwealth Rolling-Stock Pack

- **GRF ID:** `OST\x02` (`0x0254534F`)
- **Version:** 3
- **License:** GNU General Public License version 2 (GPL-2.0)
- **Source:** `commonwealth_rail.nml`

This pack provides CST train families and dedicated wagons for the 13 Commonwealth cargos for OpenSpaceTTD. The compiled package is tracked at `bin/newgrf/openspacettd_rail_v3.grf`.
- CST Pioneer 0-6-0 'Surveyor' (Steam, Baseline)
- Vulcan 2-8-0 'Frontier Hauler' (Steam, Tech: High-Adhesion Steam)
- Titan D-100 Twin-Engine Hauler (Diesel, Tech: Multi-Unit Heavy Diesel)
- CST E-40 Inter-World Catenary Hauler (Electric, Tech: High-Voltage Electrics)
- CST Mark IV 'Chimaera' Hyper-Maglev (Maglev, Tech: CST Vacuum Maglev & Vactrains)

Version 2 remains available in the original `.grf` file for existing saves. Version 3 is a separate exact-content dependency and does not silently replace it.
Version 3 adds grain refits, food containers and a ventilated livestock stockcar for the native food chain.
