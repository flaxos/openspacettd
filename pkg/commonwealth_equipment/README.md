# CST equipment

An additive GPL-2.0 cargo pack (`OST\05`, version 1) for the Mito–Merredin
sector. `MACH` occupies slot 29, following the existing Commonwealth slots 16–28.
It preserves the published industry and rail pack binaries. Manufacture modules
at a station facility: two structural steel, one wiring and one chip per module.
Gate projects accept modules only at their chosen departure supply station.
