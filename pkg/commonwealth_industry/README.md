# OpenSpaceTTD Commonwealth Industry & Cargo Pack

- **GRF ID:** `OST\x01` (`0x0154534F`)
- **Version:** 3
- **License:** GNU General Public License version 2 (GPL-2.0)
- **Source:** `commonwealth_industry.nml`

This pack provides the canonical 13 Commonwealth cargos across Pipelines A–D and their associated planetary processing facilities for OpenSpaceTTD. The compiled package is tracked at `bin/newgrf/openspacettd_industry_v3.grf`.

Version 2 remains available in the original `.grf` file for existing saves. Version 3 is a separate exact-content dependency and does not silently replace it.
The v3 definitions use slots 16–28 and explicit freight flags, preserving native farm and food cargoes.
