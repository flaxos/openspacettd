# CST star map: player acceptance

Status: **Pending human play**. Use the branch build and matching published packs.
Keep existing saves; create a new Mito–Merredin sector for this checklist.

1. Open Universe Directory → Star map. Read every star name at your usual UI scale.
   Confirm the three CST links and the three closed frontier stars. Resize the
   window; check long names, the project list, costs and access controls.
2. Send a train over CST infrastructure before researching portals. Confirm one
   toll per passage. Research Portal I/II; compare reachable stars and attempted
   out-of-range links. A direct-link shortcut must not bypass the project flow.
3. Build a departure gate and an owned logistics hub within 32 tiles. Select a
   reachable destination and an arrival zone; check the quoted reservation fee.
   Deliver steel and machine modules. Partial deliveries must update the counters.
   Cancel once and inspect the refunded stockpile. Repeat and activate when ready.
4. Confirm the new gate is private, the terrain becomes visible and the train can
   use it. Establish the colony using normal development rules, then prospect
   before placing mines. Opening a gate alone must not reveal mineral deposits.
5. Open access to a second company and set a toll. Check that its trains pay once,
   your trains travel free, and closed/private routes refuse a guest train. Save,
   restart and confirm the project, discoveries, gates and policy survive.
6. With administrator-provisioned connected hosts, use Remote stop to select an
   owned remote station and add a return station. Use native load/unload controls.
   Watch the train cross an intermediate world and deliver repeatedly. Pin a gate
   and verify the selected route. Try an offline/incompatible destination.
7. Reserve a remote arrival zone, deliver equipment, activate and wait for both
   endpoints. Briefly disconnect the authority during the handshake; restore it
   and verify one link and one equipment consumption. Use only coordinated saves
   for recovery; never restore one older server save into a live cluster.
8. From a multiplayer client, select Visit, authenticate normally, and check the
   correct company/world. Return and confirm the camera. Follow a listed remote
   train and check its orders window. A moving train's directory entry may lag.
